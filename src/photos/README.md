# Site photos (optional)

The app ships with drawn illustrations. To use real photos of your site
instead, add image files here with these names and redeploy:

| File name | Where it appears |
|---|---|
| `signin.jpg` | Sign-in screen (default: freezer aisle) |
| `signup.jpg` | Create-account screen (default: loading docks) |
| `reset.jpg` | Password reset screen (default: battery charging room) |
| `requester.jpg` | Requester home banner (default: loading docks) |

`.jpeg`, `.png` and `.webp` work too. Use landscape photos about 1600 px
wide and under 400 KB. Text sits over the lower-left of the sign-in photos,
so a darker lower half reads best. Avoid photos showing faces, customer
branding or confidential stock.
